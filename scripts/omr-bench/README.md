# اختبار قارئ ورقة الإجابة (بدون ذكاء اصطناعي)

يولّد صورًا اصطناعية تحاكي تصوير الجوال لأوراق إجابة دالة مظللة بطرق مختلفة، ثم يشغّل القارئ عليها ويعدّ الأخطاء.

**الخطأ الصامت** = قراءة خاطئة بثقة (حرف غير الذي ظلله الطالب، أو «فارغ» لسؤال مظلل). الهدف صفر.
**التنبيه** = سؤال لم يحسمه القارئ فعرضه على المعلم. آمن، لكنه يكلّف المعلم نقرة.

## التشغيل

```bash
cd scripts/omr-bench
npm i --no-save tsx @resvg/resvg-js jpeg-js     # أدوات الاختبار فقط، لا تدخل في المشروع
pip install opencv-python-headless numpy

npx tsx render.ts                 # يرسم أوراق الإجابة الفارغة إلى blocks/
python3 gen.py test 200 99        # 200 صورة عادية
HARD=1 python3 gen.py hard 150 5  # 150 صورة صعبة: ضبابية، إضاءة ضعيفة، بعيدة
npx tsx evaluate.ts test
npx tsx evaluate.ts hard
```

## قواعد التظليل الجديدة (8 نوفمبر 2026)

لم يعد القارئ يعرض أي سؤال على المعلم بسبب التظليل (`decide` في `lib/omr/reader.ts`):

| الحالة | القرار | يُحفظ في `mark_status` |
|---|---|---|
| دائرة واحدة مظللة | تُحتسب | `clear` |
| دائرة مظللة جزئيًا ولا علامة غيرها | تُحتسب | `partial` |
| دائرة مظللة وعلامة خفيفة في أخرى (مسح، لطخة) | تُحتسب المظللة | `stray` |
| دائرتان أو أكثر (كاملتان أو نصفيتان) | خطأ | `multiple` |
| لا تظليل | خطأ | `blank` |
| الصورة لم تنطبق على الدوائر | يقرر المعلم | `unclear` |
| غيّرها المعلم في المراجعة | — | `manual` |

ونسبة تظليل كل دائرة تُحفظ في `mark_fill`. رقم الطالب يبقى صارمًا كما كان.

`npx tsx evaluate-rules.ts test` يعرض نتيجة كل نوع تظليل. على نفس الصور (4,672 سؤالًا):

| النوع | النتيجة |
|---|---|
| مظلل (clean, pencil, light, stray) | 2,547 من 2,547 بالحرف الصحيح |
| تظليل جزئي | 355 من 355 احتُسب (123 سُجّل `partial`) |
| تظليل مزدوج | 321 من 321 خطأ `multiple` (كانت كلها تُعرض على المعلم) |
| فارغ | 747 من 747 `blank` |
| مسح غير نظيف | 344 احتُسبت المظللة، و10 (2.8%) حُسبت `multiple` لأن أثر المسح كان داكنًا |
| علامة X | 350 احتُسبت، وواحدة `blank` |
| أُرسل للمعلم | 0 |
| حرف خاطئ بثقة | 0 |
