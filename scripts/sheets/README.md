# أوراق دالة: النسخ الرئيسية والطباعة لكل فصل

## الفكرة
- **النسخة الرئيسية (master)** لكل اختبار: ملف PDF هو الورقة كاملة، إلا ثلاثة أشياء تختلف حسب الفصل والمدرسة:
  - رمز الفصل (QR)،
  - اسم الفصل،
  - اسم المدرسة في العنوان.

  تحمل النسخة داخلها مكان كل دائرة (قالب القارئ) ومكان هذه العناصر الثلاثة، في مفتاح `DalaSheet` في معلومات الملف.
- **ترفع النسخة الرئيسية** كورقة أسئلة للاختبار من لوحة الإدارة، كأي ورقة أسئلة.
- **عند ضغط المعلم «طباعة»** تختم المنصة نسخة فصله في المتصفح (`lib/omr/stamp-sheet.ts`): رمز الفصل من قاعدة البيانات، واسم الفصل، واسم المدرسة. ويقرأ الماسح الورقة بقالبها ويتحقق من رمز الفصل.

## الأوامر
```bash
pip install pymupdf qrcode playwright && npm ci

# النسخ الرئيسية من أوراق الأسئلة المعتمدة (صفحة لكل اختبار، وفي التذييل DALA-G6-C1-MATH-10-Vn)
python3 scripts/sheets/dala_sheets.py master --source Dala_G6_Cycle1_All_4_sheets.pdf --out masters/

# طباعة دون المنصة لقائمة فصول (school,stage,grade,class) بكود الختم نفسه، مع سجل رموز يُعاد استخدامه
python3 scripts/sheets/dala_sheets.py print --masters masters/ --classes classes.csv --out print/ [--registry print/codes.csv]
```

## ما تضيفه النسخة الرئيسية (V5)
- الفاصلة العشرية العربية «٫» بدل النقطة بين الأرقام.
- مربع لكتابة رقم الطالب، وفقاعات الآحاد ثم العشرات (١–٤٩).
- عبارة «امسح الكود بالكاميرا لترى نتيجتك».
- «أُعدّ بمنصة دالة» صغيرة في التذييل.
- العنوان «اسم المدرسة | المادة». إن طال اسم المدرسة صغر الخط، وإن لم يتسع نزل الاسم في سطر فوق المادة.
